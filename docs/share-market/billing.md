# 计费与付款

先说清楚三件事：

1. **平台不经手钱。** 没有充值、没有余额、没有托管、没有抽成。
2. **账是赊的。** 先用后付，按「你 × 某个供应商」聚合成一本 USD 账。
3. **付款在线下。** 你按供应商给的收款方式付，然后在系统里声明，供应商确认到账。

## 赊账账户

每一对「买家 + 供应商」有且只有一本账，**Share Market 和 Client Market 共用**。你从同一个人那里租了三个拼车位加一台主机，还是一本账，一起出账。

账户货币是 **USD**。人民币只作展示换算，默认 `1 USD : 7 CNY`，由 Router 管理员维护。未出账的估算按当前汇率折算，**账单一旦出具就冻结当时的汇率、人民币总额和明细**。记账始终是 USD，CNY 不参与计算。

## 12 小时试用

每段付费授权服务的**前 12 小时健康服务时长不计费**。

注意是「健康时长」不是「自然时长」：Owner 的机器离线的那段时间不算在这 12 小时里，也不计费。

## 费用怎么累计

试用期结束后，Router **只按它观测到的健康服务区间**累计费用。

- 服务不可用的时间：不计费
- 状态未知的时间：不计费
- 按位子的每日价格折算实际服务时长

这条规则是偏向买家的：有疑问的时间一律不算钱。

## 什么时候出账

四个触发点，任一发生就合并出账：

| 触发 | 说明 |
| --- | --- |
| 额度用满 | 有限额度累计到上限 |
| 你主动清账 | 随时可以 `request-settlement` |
| 供应商主动清账 | 供应商也可以发起 |
| 最后一个服务结束 | 你和这个供应商之间不再有活跃服务 |

**有限额度用到 80% 时，你和供应商都会收到预警。** 别等到用满才处理。

无限额度不会自动出账，只接受主动清账。

**出账即暂停相关服务。** 账单未结清期间，你从这个供应商那里租的服务会被暂停 —— 注意固定期限**不会因此顺延**。

## 付款流程

```text
出账
 └─► 看账单：金额、明细、供应商的收款方式与联系方式
      └─► 线下付款（按账单上冻结的那份收款资料）
           └─► 在系统里声明已付（可附 reference / 备注 / 凭证）
                └─► 供应商确认到账
                     └─► 仍在有效期内的服务恢复
```

出账时会把供应商**当时的**收款方式和联系方式冻结进这张账单。之后供应商改资料，不影响这张已出的账单 —— 你付的永远是账单上写的那个地址。

**逾期会限制你继续使用市场赊账。** 只有供应商确认到账，或管理员作废该账单，才解除限制。

## 在哪儿看

| 页面 | 看什么 |
| --- | --- |
| `/account/billing` | 赊账账户、待处理、应付、历史账单、争议 |
| `/account/payments` | 付款声明与凭证 |
| `/account/rentals` | 租约状态、剩余期限 |
| `/account/consumer-usage` | 实际用量 |

账务页按待处理 / 应付 / 应收 / 历史 / 管理员争议分区。你既可能是买家（应付）也可能是供应商（应收），在同一页。

## 免费位

免费拼车位**完全不进账务系统**：不要求信用额度、不产生账单、不形成赊账关系。

租自己的付费主机也按免费处理，不会给自己记债。

## 争议

对账单有异议可以发起争议，由 Router 管理员裁决。管理员可以作废账单。

争议信息（原因、金额、付款 reference）在系统内是公开可读的事件数据 —— 不要在里面写任何凭据。

## 供应商可以关掉赊账关系

供应商可以**随时永久关闭**对你的赊账关系。这个动作即时生效：

- 即使有待处理账单，关闭意图也会立即锁定并终止服务
- 清账或账单作废后**不会恢复**
- 之后双方**禁止再次建立付费租约**

所以按时结账不只是钱的问题。
